# YT Web Media

Codemagic-ready Android project.

Upload the contents of this folder to a GitHub repository, connect that repository
to Codemagic, and run the `android-debug` workflow.

The APK will appear under build artifacts.

Current build is the first installable proof of concept:
- GeckoView
- YouTube TV web interface
- Android TV launcher support
- Remote events passed to Gecko

The custom WebExtension navigation, SponsorBlock, uBlock integration and Android
Auto Media3 layer are subsequent development stages after confirming this base
APK installs and YouTube loads correctly on the target hardware.
